# Security Policy

## Supported versions

Security fixes are coordinated for the latest GitHub release and the current Microsoft Store release of PageArc. Older builds may no longer receive fixes; please reproduce issues on the latest version first.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private security advisory flow for `KiYouJyo/PageArc`, or contact the maintainers privately through the repository owner profile. Include the affected version, installation channel, Windows version, reproduction steps, and a minimal impact description. Remove book contents, personal data, credentials, WebDAV passwords, and local file paths from reports.

We will acknowledge a report when it is received, investigate it privately, and publish a coordinated fix or mitigation when appropriate. We cannot promise a fixed response time or a bounty.

## Scope

Reports involving the application, its packaged runtime, update channel, package identity, or bundled third-party runtime are in scope. DRM circumvention, malicious ebook content supplied by a reporter, and vulnerabilities in unrelated upstream software should be reported to the relevant vendor as well.
