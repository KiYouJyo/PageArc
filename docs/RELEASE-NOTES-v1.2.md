# PageArc v1.2

PageArc 1.2 将 SpatialViewer v0.3.4 已确认的标题栏与标签页视觉规则迁移到阅读器，同时保留 PageArc 既有阅读、书库、转换、数据与更新功能。

## 标题栏与标签页

- 标题栏改为与 SpatialViewer 一致的透明 Mica 承载方式，并采用相同的 48 DIP 标题栏、104 DIP 品牌区、132 DIP 系统按钮预留区与 32 DIP 标签页高度。
- 深色与浅色模式统一采用 SpatialViewer 已确认的系统标题栏按钮前景、悬停和按下反馈；窗口激活状态与主题切换后会重新同步。
- 选中标签继续使用轻量填充、细边框和 SemiBold 标题；未选中标签保持弱填充，但不再降低可用标签文字透明度。
- 移除 PageArc 原有的选中标签整体透明度脉冲，避免点击时出现与 SpatialViewer 不一致的亮暗跳变。

## 自适应标签栏

- 标签页空间充足时统一保持最高 220 DIP 宽度。
- 当标签总宽达到标题栏可用空间时，所有标签同步等宽压缩，行为与 Chrome / Firefox 及 SpatialViewer v0.3.4 一致。
- 窗口缩放、打开或关闭标签后都会自动重新计算宽度；关闭标签后剩余标签自动回弹。
- 标签最小宽度为 72 DIP，并始终为“+”新建标签按钮保留空间；超过最小宽度承载能力后继续使用既有水平滚动作为兜底。
- 标签重排继续使用 WinUI 原生 `RepositionThemeTransition`，不会影响 Reader 内容或页面布局。
