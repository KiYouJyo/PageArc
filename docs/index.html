专注于流式电子书格式的离线优先 Windows 阅读器。以原生 WinUI 3 体验阅读 EPUB、MOBI、AZW3、FB2 与 LIT，并保持原始电子书文件不被修改。

流れる電子書籍形式に集中した、オフライン優先の Windows リーダー。元の電子書籍を変更せず、原生 WinUI 3 で読書できます。

An offline-first Windows reader for flowing ebook formats. Read EPUB, MOBI, AZW3, FB2, and LIT with a native WinUI 3 experience while keeping original files untouched.
