Windows 原生体验Windows ネイティブ体験A native Windows experience

以 WinUI 3 与 Windows App SDK 构建原生阅读器。书库、进度、书签与笔记保存在本机；阅读和转换使用副本或新文件，保留原始电子书。WinUI 3 と Windows App SDK によるネイティブリーダー。ライブラリ、進捗、ブックマーク、ノートはローカルに保存。読書・変換はコピーか新規ファイルを使用し、原本を保持します。A native reader built with WinUI 3 and Windows App SDK. Library data, progress, bookmarks, and notes stay local; reading and conversion use copies or new files to preserve originals.

  • EPUB、FB2 使用内置解析器，MOBI、AZW3 与 LIT 通过对应兼容层接入流式阅读。EPUB・FB2 は内蔵パーサー、MOBI・AZW3・LIT は対応する互換レイヤーでリフロー読書へ。EPUB and FB2 use built-in parsers; MOBI, AZW3, and LIT use their compatibility layers for reflow reading.
  • 转换运行时独立分发，首次需要时确认下载，优先复用系统已有 calibre。変換ランタイムは独立配布。初回に確認して取得し、既存の calibre を優先利用。The conversion runtime ships separately, downloads with confirmation when needed, and reuses installed calibre.
  • 不要求账户；WebDAV 同步与更新检查按用户操作联网。アカウント不要。WebDAV 同期と更新確認はユーザー操作に応じて接続。No account required; WebDAV sync and update checks connect on user action.

  • 基础阅读器不再捆绑 calibre，减少安装包体积。基本リーダーに calibre を同梱せず、パッケージを小型化。The base reader no longer bundles calibre, reducing package size.
