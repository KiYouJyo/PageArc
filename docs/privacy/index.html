简体中文

PageArc 不要求注册账户，也不以应用功能为目的收集、出售或上传个人信息。

  • 书库索引、阅读进度、阅读偏好、笔记、书签、封面和缓存保存在用户本机。
  • PageArc 不修改原始电子书文件；转换结果会写入新文件。
  • 用户主动检查更新时，应用访问 PageArc 官方 GitHub Release API。
  • 用户主动配置并执行 WebDAV 同步时，应用使用用户提供的 HTTP/HTTPS 地址和凭据上传或下载阅读数据备份；凭据保存在本机系统凭据存储中。
  • 除上述用户主动操作外，正常阅读、解析和转换不依赖网络。

日本語

PageArc はアカウント登録を必要とせず、個人情報を収集・販売・アップロードしません。ライブラリ、進捗、設定、ノート、ブックマーク、表紙、キャッシュは端末内に保存されます。更新確認またはユーザーが設定した WebDAV 同期を実行した場合のみネットワークを使用します。WebDAV の資格情報は端末のシステム資格情報ストアに保存され、元の電子書籍ファイルは変更しません。

English

PageArc requires no account and does not collect, sell, or upload personal information for normal app functionality. Library metadata, reading progress, preferences, notes, bookmarks, covers, and caches remain on the device. Original ebook files are never modified. Network access occurs only when the user checks for updates or explicitly configures and starts WebDAV sync. WebDAV credentials are stored in the local system credential store.

Questions or privacy requests: use the repository's private contact route. Do not include ebook contents, passwords, or personal data in public issues.
